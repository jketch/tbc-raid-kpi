Raider Score — How the Number Is Built

Officer reference · v2 · Jun 2026

A single 0–100 per raider, blended from five pillars. Built so nobody is forced to the bottom and every spec is judged by what it is invited for. Performance is now input-based — what the player controls, not buff/tempo-inflated parse.

The composite
Score = weighted blend of Prep · Performance · Execution · Survival · Utility, renormalized over the pillars that apply to that raider (a pillar that doesn't apply drops out — never a damaging zero).
Weights are set per spec — not one-size-fits-all (the archetype)

How it stays honest — and how it's checked
  • Input over output — Performance grades activity + cadence + uptime (what you do), not buff/tempo-inflated parse.
  • Absolute targets, not a curve — nobody is forced to last place each week.
  • Null, not zero — a pillar/facet that doesn't apply drops out and renormalizes.
  • Positive-only extras — assigned utility can only raise a score, never sink it.
  • Per-spec weighting — activity and a tank's mitigation aren't compared head-to-head.
  • Scored once — each ability lives in exactly one pillar (no double-count).
  • Unit-tested core — the scoring logic is a fenced module run on every commit.
  • v2 tuning — every weight/target is labeled and calibrated against live weeks.
