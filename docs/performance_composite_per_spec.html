Performance Composite — Per-Spec Logic

Officer reference · v2 · Jun 2026

How the Performance pillar is scored for each DPS spec, and which inputs live in Performance vs the Utility pillar — so no input is counted twice.

Performance = 0.7 · activity% (boss + trash)  +  0.3 · overlay  +  engineering bonus. Activity (GCD uptime) is the buff/tempo-independent backbone. The overlay averages two ability classes: on-CD (rate-scored — press your cooldown on time) and maintain (DoT / self-buff uptime % — kept it up, vs a loose target). Filler spells (Shadow Bolt, Steady Shot, Lightning Bolt, Sinister Strike, Starfire, Arcane Blast) fold into the activity backbone — not scored. Optional maintains drop out if the spec doesn't run them (no penalty). Parse % is shown as context, not scored. Engineering (sapper/bomb) only lifts, never drags.

Tier sets the composite weighting (perfArchetype): dps0 pure parse (perf ×2.25, util ×0.5) · dps1 utility-flavored (perf ×1.75, util ×1.25) · dps2 utility-first — boomkin, the buff-bot (perf ×1.0, util ×2.0). Tiers are set by how much a spec's utility costs output: rotational/no-cost utility (Ret seal-twist, Shadow VT) → judged on Performance (dps1); a spec that exists for its raid aura → Utility-weighted (dps2). Hunters/healers/tanks resolve by role. Hunter Steady:Auto ratio is shown as a diagnostic, not scored (it's haste-driven).
Double-count check — clean
Every Performance-scored ability was cross-checked against every Utility facet: no input is scored in both pillars. It holds by construction — each utility ability is tagged utility and kept out of the maintain/on-CD lists.
  • Seal-twisting (Ret): Seal of Command → Utility only (twist). Crusader Strike + Judgment → Performance only. Different abilities — clean split. ✓
  • Slice and Dice (Combat): its uptime is a Performance maintain; it's not a Utility facet — scored once. ✓
  • Spec-baseline debuffs: Curse of Elements (affli), Faerie Fire (boomkin), Expose Weakness (survival) are scored as Utility uptime — and deliberately kept OUT of those specs' Performance maintain list. Scored once. ✓
  • None of {Battle Shout, Windfury, Totem of Wrath, Misdirection, Sunder, Expose Armor, Seal of Command, CoE, Faerie Fire, Expose Weakness} appears in the Performance overlay. ✓
The one conscious cross-pillar split — Vampiric Touch (decided)
VT is the single ability that lives in both pillars, by design: its uptime (did the shadow priest keep it rolling — execution) is a Performance maintain, while its mana-returned value (the raid battery it feeds) is a Utility facet (mana). These are two different metrics of one ability — keeping it up vs how much mana it returned — not a double-count of the same number. Every other ability is scored in exactly one pillar.
Prep / Execution / Survival pillars are spec-agnostic (consumables+gear / avoidable+AoE-into-allies / deaths+healthstone) — no per-spec double-count risk. Source of truth: PERF_ONCD + PERF_MAINTAIN + utilFacetsFor in template.html · framework: docs/DPS_SPEC_PERFORMANCE_FRAMEWORK.md
